This is the frontend for the Warehouse Inventory Management System built for a hackathon project.  
It provides a user-friendly interface for inventory managers and warehouse staff to manage stock operations, view dashboards, and perform stock-related tasks.

## Features

- Product Management: Add, update, and view products.  
- Receipts & Delivery Orders: Manage incoming and outgoing stock.  
- Internal Transfers: Track stock movement within warehouses.  
- Inventory Adjustments: Fix mismatches between recorded and physical stock.  
- Dashboard: Real-time KPIs like total stock, low/out-of-stock items, pending deliveries, etc.  
- Filters: By document type, status, warehouse/location, and category.  
- Authentication: User sign-up/login.

## Tech Stack

- React (Frontend framework)  
- Vite (Build tool / Dev server)  
- Tailwind CSS (Styling)  
- JavaScript / TypeScript (Code)
